突然发觉自己快半年没有认真写过开发代码了，如果不算每天刷的那几道 LeetCode。  
  
最近《我不得不把才华埋葬在昨天》这篇文章很火，看完之后我心里也久久不能平。  
  
LLM从诞生开始，就一直伴随着质疑声。当然也包括我。  
  
从 GPT-1、GPT-2 的 toy 级别，尚未真正走入大众视野。到 GPT3 的初现雏形，或许还不太显眼。再到后来 CoT 之类的方法出现，模型的推理能力开始被挖掘。2024 年，OpenAI 推出 o1，推理时代的开始。  
  
转折点可能是 DeepSeek R1 的面世，人们发现仅仅通过大规模的 RL，也可以让一些复杂的推理行为逐渐涌现出来。

此后 AI 界好像开启了军备竞赛，Openai 和 Anthropic 逐渐成为 LLM 的两大巨头，以至于现在的几周一个新模型。  
  
我偶尔会想起 2025 年，AI 还不那么聪明的时代。那时候还有很多人认真地一行一行手搓代码，并且以真正读懂一份源码为荣。

当时我正在学 UCB 的几门入门课，CS61A 和 CS61B。学 61B 还费了不少劲，用 Java 从头写了一个简易版 Git。  
  
当时 infra 的学无穷尽深深吸引着我。我甚至认真想过，以后要成为一个 infra 工程师。

手搓代码才是最帅的！

至于做 AI 的？

不过是一群调包侠罢了。

——现在的我只能苦笑童言无忌，想穿越回去给自己一巴掌。
  
然后时间到了今天。

人均一个 Claude Code 或者 Codex。写一个网站已经不算什么了，搭项目、读源码、改 bug、重构代码也越来越普通。

以前被认为门槛很高的 CUDA kernel 也慢慢成为了AI的舒适区。

每天睁开眼睛，都可以看到新的 AI 新闻。什么 Openai 攻破十大难题啦，哪家发了新模型又 SOTA 啦…看多以后，甚至会产生一种奇怪的麻木感。

虽然每个人对 AGI 的定义不同，但我们是不是真的在接近某个东西？又或者，几年之后回头看，会发现今天所有的狂热都只是一场巨大的泡沫？

我不知道。

偶尔会想起以前背着书包去图书馆，坐在电脑前一行一行写 Java，好不容易跑通 Git，开心了好久。回想起来会觉得有一些恍惚。

仅仅两年。

好像已经是上一个时代了。
